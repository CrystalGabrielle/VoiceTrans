# VOICE TRANS · 本地实时直播变声系统

一套完全跑在本机的实时变声器：麦克风进 → 变声处理 → 虚拟声卡出 → 直播软件当麦克风用。
**不联网、不上传、不依赖任何在线服务**，48 kHz 下单块 256 采样，端到端延迟约 **65 ms**，CPU 占用 **单核 3% ~ 20%**（看预设）。

- 变调 ±12 半音（精度实测偏差 < 0.3%），**共振峰（音色）独立可调** —— 所以能做到「男变女」而不是单纯的「加速」音
- 14 组直播预设：甜美女声 / 萝莉 / 御姐 / 磁性大叔 / 机械音 / 深渊怪兽 / 电话音 / 耳语…
- 链路完整：噪声门 → 低切高切 → 三段 EQ → 变声 → 失真 → 机械调制 → 气声 → 压缩 → 混响 → 限幅
- **自动响度对齐**：换预设、改音高时音量不会忽大忽小（1.5 秒慢速自动增益）
- 浏览器控制台，滑杆实时生效；带输入/输出电平表、一键录制、旁通 A/B 对比

## 1. 三步跑起来

| 步骤 | 操作 |
| --- | --- |
| ① | 双击 **`安装环境.bat`**（只需一次，装 numpy / scipy / sounddevice 到项目内的 `.venv`） |
| ② | 双击 **`启动变声器.bat`**，浏览器自动打开控制台 `http://127.0.0.1:8765/` |
| ③ | 在右侧「设备」里选好麦克风和输出去向，点「应用并重启音频」，然后点一个预设开始说话 |

第一次建议先点 **`自检.bat`**：会验证变调精度、共振峰、全部预设的稳定性，以及麦克风/扬声器能否正常打开。

> 只想自己听效果：输出去向选耳机/扬声器即可（**别用外放 + 麦克风，会啸叫**）。
> 要进直播：必须先装虚拟声卡，见下一节。

## 2. 让直播软件听到变声（关键一步）

直播软件只认「麦克风设备」，它拿不到本程序内部的声音。所以要一根**虚拟音频线**：

```
麦克风 ──► VOICE TRANS 变声 ──► CABLE Input（虚拟线的入口）
                                        │
                                   虚拟线内部
                                        │
直播软件 ◄── 麦克风选 CABLE Output（虚拟线的出口）
```

### 2.1 安装虚拟声卡（VB-CABLE，免费）

1. 双击项目根目录的 **`安装虚拟声卡.bat`**（驱动包已放在 `tools/VBCABLE/`，无需联网）
2. 弹出 UAC 点「是」→ 在安装窗口点 **Install Driver** → 确定
3. **重启电脑**（驱动必须重启才生效）
4. 重启后右下角音量图标里会多出 `CABLE Input` / `CABLE Output` 两个设备

### 2.2 在变声器里设置

打开控制台 → 右侧「设备」：

- **麦克风输入**：你的真实麦克风（如 `麦克风 (USB Audio Device) · Windows WASAPI`）
- **输出去向**：`CABLE Input (VB-Audio Virtual Cable) · Windows WASAPI`
- 点「应用并重启音频」；提示条变绿「已路由到虚拟声卡」即为成功

> 刚装完驱动看不到 CABLE？点一下「刷新设备列表」。

### 2.3 在直播软件里设置

| 软件 | 位置 | 选什么 |
| --- | --- | --- |
| **OBS Studio** | 来源 → `+` → 音频输入采集 → 设备 | `CABLE Output (VB-Audio Virtual Cable)` |
| **抖音直播伴侣** | 设置 → 音频 → 麦克风 | `CABLE Output (VB-Audio Virtual Cable)` |
| **B 站直播姬** | 设置 → 音频 → 麦克风 | `CABLE Output (VB-Audio Virtual Cable)` |
| **视频号 / 快手直播** | 开播设置 → 麦克风 | `CABLE Output (VB-Audio Virtual Cable)` |
| **腾讯会议 / YY / Discord** | 音频设置 → 输入设备 | `CABLE Output (VB-Audio Virtual Cable)` |

要点：**变声器输出 → CABLE Input，直播软件输入 → CABLE Output**，两边别选同一个。

想同时自己监听：在 OBS 里给这个音频源开「监听并输出」，或把系统播放设备保持不变（变声器只往虚拟线送，不影响你自己听别的声音）。

## 3. 控制台怎么用

- **左侧预设**：点一下整套参数就位，适合直接开播。改任意滑杆会自动取消高亮，表示这是自定义状态。
- **中间滑杆**：拖动即刻生效（内部做了 5 ms 平滑，不会有咔哒声）。
- **右上设备**：换麦克风/输出、改采样率与缓冲、重启音频。
- **电平表**：说话时**输入峰值落在 −12 ~ −6 dB** 最健康；贴顶就调「输入增益」往下。
- **录制**：把处理后的声音存成 WAV，落在 `recordings/`，用来回听调参效果。
- **快捷键**：`B` 旁通（原声/变声对比），`R` 开始或停止录制。

## 4. 参数与预设

### 核心两个

| 参数 | 作用 | 经验值 |
| --- | --- | --- |
| **音高** | 改音调，±12 半音 = 一个八度 | 男→女 `+5 ~ +7`；女→男 `-4 ~ -6`；超过 ±7 容易有金属味 |
| **音色（共振峰）** | 改"像谁"，不动音高 | 跟音高同向但幅度更小：男→女音高 +6 时音色 +3.5 左右最自然 |

音高单独拉高、音色不动 = 像同一个人变调；音色一起拉高 = 变成了另一个人（声道更短）。这就是"变声"和"加速"的区别。

### 预设对照

| 预设 | 音高 | 音色 | 配方要点 |
| --- | --- | --- | --- |
| 甜美女声 | +8.5 | +3.2 | 低频 −3 / 中频 +2.5 / 高频 +2.5，齿音抑制 40，气声 3，压缩 16 |
| 萝莉音 | +10 | +6.5 | 高频 +3，气声 6 |
| 御姐音 | +3 | +2 | 低频 +1.5，压缩 40 |
| 清亮少年 | +2.5 | +1.2 | 高频 +2 |
| 磁性大叔 | −3.5 | −2.5 | 低频 +3，失真 18 |
| 播音主持 | −1.5 | −0.8 | 压缩 55，三段 EQ 各 +2 |
| 机械音 | −1 | −1 | 机械调制 70% @45 Hz |
| 深渊怪兽 | −7 | −6 | 失真 45，混响 45 / 空间 85 |
| 外星访客 | +7 | −5 | 调制 30% @80 Hz |
| 电话听筒 | 0 | 0 | 高切 3.4k / 低切 340，失真 35 |
| 耳语密语 | +0.5 | 0 | 气声 75，关噪声门 |
| 空谷回声 | 0 | 0 | 混响 55 / 空间 90 |
| 电音花栗鼠 | +12 | +8 | 极限娱乐向 |

其余参数：输入增益、噪声门（阈值）、低切/高切、低频/中频/高频、齿音抑制、失真染色、机械调制与频率、气声、混响量与空间、压缩、输出增益、限幅、静音、旁通。

## 5. 延迟与性能

本机实测（USB 麦克风 → 板载输出，48 kHz / 256 采样）：

| 指标 | 数值 |
| --- | --- |
| 端到端延迟（含算法一帧 21 ms） | **约 65 ms** |
| CPU（原声直通 / 甜美女声 / 最重特效） | 3% / 11% / 13%（单核，自检口径；齿音抑制会增加约 3 个点） |
| 变量 | 缓冲 128 → 更低延迟但更吃 CPU；512 → 更稳 |

响度由内置 AGC 自动对齐：切换预设或大幅改音高时，音量会在 1.5 秒内回到与输入相当，不会突然变小或爆音。

觉得延迟大：缓冲调到 `128`，采样率保持 48 kHz，直播软件里再把音画同步微调一下。
觉得卡顿/爆音：缓冲调到 `512`；关掉其他占用麦克风的程序（微信、QQ、钉钉会独占）。

## 6. 常见问题

**对方听不到 / 直播没声音**
1. 变声器「输出去向」是否选了 `CABLE Input`；2. 直播软件麦克风是否选了 `CABLE Output`；3. Windows 音量合成器里 `CABLE Input` 是否被静音；4. 是否点了「应用并重启音频」。

**自己听不到**
输出去向选了虚拟声卡，你自己当然听不到——虚拟线把声音送给了直播软件。想同时听就在 OBS 里给该音频源开「监听并输出」。

**啸叫 / 尖锐回授**
外放 + 麦克风形成的。改用耳机，或把「输出去向」设为虚拟声卡（不再从扬声器放出来）。

**声音有金属味、像机器人**
音高改太多（> ±7）或音色与音高差距过大。把音高往回收，减一点失真/调制，加 10% 混响遮一下。

**变声不明显**
±2 半音以内人耳基本听不出。男变女至少 +5 半音、音色 +3；同时确认「旁通」没被打开。

**电流声 / 底噪大**
噪声门阈值往上调到 −45 左右（说话时仍能正常打开），并检查麦克风增益是不是拉太满。

**CABLE 设备不见了**
驱动在系统更新后可能掉，重跑 `安装虚拟声卡.bat` 并重启。

**换设备后没反应**
点「刷新设备列表」→ 选设备 → 「应用并重启音频」。

**双击 .bat 报「不是内部或外部命令」，满屏乱码**
批处理文件被存成了 UTF-8，而 cmd 用 GBK 解析，中文会把行切错。本项目所有 `.bat` 都已按 **GBK + CRLF** 保存。如果你手动改过脚本，请用记事本「另存为」时把编码选成 **ANSI**，换行保持 Windows 格式，否则同样会报这个错。

## 8. 它是怎么发声的

变声的核心是**相位声码器**：把音频切成 1024 点一帧（50% 以上重叠）做 STFT，逐帧估算每个频点的真实瞬时频率，再把频谱按比例搬移后重建，这样改变音高而**不改变时长**（简单的重采样会让语速变快，一听就假）。

搬移频谱时，共振峰也会跟着一起搬——所以单靠变调，声音会像"花栗鼠"。因此额外做了一步**谱包络替换**：分别估计输入帧和输出帧的谱包络（对数幅度平滑），把输出包络替换成"输入包络按音色比例缩放"后的版本。这样音高和音色就解耦了，可以"音高 +6、音色 +3.5"，听起来才是换了一个人。

其余效果都是块级因果处理：RBJ 双二阶做 EQ，控制率包络做门限与压缩，块级梳状+全通做混响（零额外延迟），最后软限幅保护。算法额外延迟只有一帧（21 ms）。

频点搬移会破坏帧间相位相关性，重建后响度会掉几 dB、且随变调量变化，所以链路末端加了一条 1.5 s 的慢速 AGC 做响度对齐——它只修正"整体音量偏移"，不压动态，听起来就是"换个预设音量不变"。

**和 AI 变声的区别**：本系统是 DSP 变声，改变的是音高/音色/质感，音色仍属于"类人声"，不挑显卡、不吃模型、延迟 65 ms。如果你要的是"变成某个具体的人/主播的音色"，那是 RVC 这类语音转换模型的事（需要 GPU、几百 MB 模型、延迟通常 100 ms 以上）。两者可以串联：把本系统的输出当成 RVC 的输入即可，或者直接用 VCClient 这类现成方案。

**隐私**：全部处理在本机内存里完成，不联网、不上传，录制文件只写本地 `recordings/`。
